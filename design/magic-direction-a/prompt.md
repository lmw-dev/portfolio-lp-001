# Magic Patterns Direction A — Clean Professional

> 状态：draft  
> 用途：Magic Patterns 生成输入 + UI 设计师参考  
> 版本：v0.2 — 修正内容漂移，删除不可靠内容

## 1. 方向定义

**Direction A** 采用 Clean Professional 风格，适合需要建立信任感的 B2B SaaS 服务场景。

**视觉关键词：**
- Minimal
- Professional
- White background
- Blue accent colors
- Clean typography
- Trust-focused

## 2. Magic Patterns Prompt

```

Hero Section:
```

## 3. 设计规范

### 颜色

```
Primary: #2563EB (Blue)
Secondary: #1E40AF (Dark Blue)
Accent: #3B82F6 (Light Blue)
Background: #FFFFFF (White)
Surface: #F9FAFB (Light Gray)
Text Primary: #111827 (Near Black)
Text Secondary: #6B7280 (Gray)
Border: #E5E7EB (Light Border)
```

### 字体

```
Headline: Inter, 700, 48px/1.1
Subheadline: Inter, 400, 20px/1.5
Body: Inter, 400, 16px/1.6
Caption: Inter, 500, 14px/1.4
```

### 间距

```
Section padding: 80px 0
Container max-width: 1200px
Grid gap: 24px
Card padding: 32px
```

### 圆角

```
Button: 8px
Card: 12px
Badge: 16px (pill)
```

## 4. 适用场景

- 需要建立专业信任感
- 目标客户为中小企业决策者
- 强调可靠性和专业性
- 保守但现代的设计语言

## 5. 风险

- 可能显得过于保守
- 与其他 B2B SaaS 页面相似度较高
- 需要高质量文案支撑
