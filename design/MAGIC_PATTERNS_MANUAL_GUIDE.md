# Magic Patterns 执行指南（手动）

> browser 工具无法访问 magicpatterns.com。以下为精确手动步骤。

## Step 1: 登录

1. 打开 https://www.magicpatterns.com
2. 登录你的账号

## Step 2: Direction A — Clean Professional

1. 点击 **New Project** 或 **Create**
2. 项目名称：`LP-001-Direction-A`
3. 粘贴 `design/magic-direction-a/prompt.md` 中的 Prompt
4. 点击 **Generate**
5. 等待生成完成
6. 截图保存：
   - 全页截图
   - Hero 区域
   - Connected Workflow 区域
   - Service Cards 区域
   - Lead Form 区域
   - 移动端预览

## Step 3: Direction B — Modern Tech-Forward

1. 点击 **New Project** 或 **Create**
2. 项目名称：`LP-001-Direction-B`
3. 粘贴 `design/magic-direction-b/prompt.md` 中的 Prompt
4. 点击 **Generate**
5. 等待生成完成
6. 截图保存（同上）

## Step 4: 保存证据

将截图保存到：
```
design/magic-direction-a/screenshots/
design/magic-direction-b/screenshots/
```

文件名建议：
- `full_page.png`
- `hero.png`
- `workflow.png`
- `services.png`
- `form.png`
- `mobile.png`

## Step 5: 记录项目信息

在 `design/magic-direction-a/project-reference.md` 和 `design/magic-direction-b/project-reference.md` 中补充：
- `magic_project_name`: Magic Patterns 中的项目名
- `magic_project_url_or_id`: 项目 URL 或 ID

## 注意事项

- 不要直接导入 Mercury HTML 作为设计起点
- 优先使用已冻结 Prompt 独立生成
- 不得生成虚构客户、Logo、评价、指标或转化数据
- 两套都必须保持 B2B 可信度
- Direction B 可现代，但不要过度炫技
